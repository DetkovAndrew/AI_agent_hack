# План проверки

Методика: `knowledge/methods/validation.md`. Шаблон: `knowledge/templates/validation_plan.md`.

Для каждой ключевой гипотезы, на которой держится стратегия (начни с самой рискованной):
- ожидаемое изменение (метрика, направление, порог — «не меньше чем»);
- с чем сравниваем (контрольная группа, A/B, до/после с поправкой на сезонность, бенчмарк);
- срок наблюдения и минимальный объём выборки (оценка, расчёт — в `analysis/`);
- нежелательные последствия и guardrail-метрики (каннибализация, отток, нагрузка на поддержку);
- решение по итогу: продолжить / доработать / остановить — и кто решает.
Синтетические интервью в плане проверки — только как источник гипотез, не как способ проверки.

`pf.py check`, `pf.py stage decision --next "..."`.
