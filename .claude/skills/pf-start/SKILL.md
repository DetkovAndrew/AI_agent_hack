# Старт / продолжение

1. `python3 tools/pf.py list` — есть ли проекты.
2. Если PM продолжает работу — `pf.py use <slug>` → `pf.py status --brief` → прочитай
   `projects/<slug>/STATUS.md` и последние 15 строк `journal.md` → выполни «Следующее действие».
   Ничего не переделывай заново. Одной строкой скажи PM, где мы и что делаешь дальше.
3. Если задача новая:
   - придумай короткий slug латиницей по сути вопроса;
   - `pf.py init <slug> --title "<вопрос PM своими словами>"`;
   - если PM приложил файлы — скопируй их в `projects/<slug>/inbox/` (не регистрируй пока);
   - переходи к `/pf-intake`.
4. Кратко объясни PM, как будет идти работа (5 строк): постановка → материалы →
   исследование → варианты → **твой выбор** → стратегии → план проверки → решение.
   Скажи, что он может в любой момент остановить, уточнить или исправить.
