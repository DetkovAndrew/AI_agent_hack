# Опрос ушедших подписчиков, октябрь 2026

> ВЫМЫШЛЕННЫЕ МАТЕРИАЛЫ ДЛЯ ТРЕНИРОВКИ АГЕНТА.

Опрос в приложении после отмены подписки, 1–31 октября 2026. Ответили 2 940 человек из 50 тыс.
отменивших (5,9%), можно было выбрать до двух причин. Выборка смещена к тем, кто открыл приложение
после отмены.

| Причина | Доля ответивших |
|---|---|
| Пользуюсь только одним сервисом, переплачиваю | 41% |
| Дорого в целом | 22% |
| Нет нужных фильмов / новинки платные | 18% |
| Перешёл на семейный тариф у другого оператора | 11% |
| Другое | 8% |
