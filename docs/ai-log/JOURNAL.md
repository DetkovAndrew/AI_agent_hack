# Журнал работы с ИИ

Материал для разделов описания работы «время, расходы, ошибки и помощь человека» и «как шла
работа с нейросетями». Записи добавляются по ходу, а не задним числом.

Формат записи: дата · кто (человек / Claude Code / Codex) · задача → результат · ошибки ИИ и
как их нашли · что сделал человек. Расход — по `pf.py cost` или по счёту сервиса; если оценка,
так и пишем.

## 2026-11-16 — ночной прогон и доработки

**4. Исправления — PR #1** (https://github.com/NursuUwU/AI_agent_hack/pull/1). Claude Code:

**5. Сборщик PDF и этот журнал.** Claude Code перенёс из решения команды по треку
«Вайб-кодинг» сборку `report.md → HTML → PDF` (`scripts/report/build.mjs`, шрифт Onest, OFL):
пути через `fileURLToPath`, чтобы сборка работала и в Windows, нейтральное оформление.
Черновик `docs/submission/report.md` уже закрывает разделы, которых требует кейс; то, что
зависит от демо-проекта, помечено блоками `::: todo`.

**6. База знаний между проектами** (ветка `feat/knowledge-base`, поверх PR #1). Claude Code:
`pf.py kb` — запись, перенос из проекта, поиск, связи, отзыв и замена с историей. Главное
решение — происхождение записи определяет, чем она станет в новом проекте: факт возвращается
только со своим источником, вывод агента — только гипотезой, решения и слова человека —
допущениями; синтетика и факты без источника в базу не попадают. Поиск без внешних библиотек:
триграммы и основы слов, чтобы русская морфология не мешала («онбординге андроида» находит
«Онбординг на Android»). 4 новых теста, всего 11.
- Ошибка ИИ при написании тестов: сообщение об отказе было со статусом по-английски
  («retracted»), тест ждал «отозвана» — заметили по падению теста, статусы переведены.
- Ограничение, записанное честно: поиск лексический; «по смыслу» обеспечивает агент,
  формулируя запрос 2–3 способами (правило в AGENTS.md §8).

**8. MCP-сервер** (ветка `feat/mcp-server`, PR #5). Claude Code: `tools/mcp_server.py` — 19
инструментов поверх `pf.py` для Cursor и Codex, только стандартная библиотека. Решение: сервер
не дублирует логику, а запускает `pf.py`, поэтому проверки и блокировка общие; в Claude Code не
подключён, чтобы не было двух наборов одинаковых инструментов.
- Проверка: тест по протоколу (initialize, уведомление без ответа, tools/list, отказ для факта
  без источника). Проверку внешним клиентом (MCP Inspector) запустить в песочнице не дали —
  живой Cursor остаётся непроверенным, просьба в PR.
- Помощь человека: подтверждения push и PR — проверка разрешений Claude Code требует их на
  каждое новое действие с GitHub.
- Ошибка ИИ (Claude Code): в коммит базы знаний попали 179 файлов `scripts/report/node_modules`.
  Причина — `git add -A` на ветке, где `.gitignore` ещё не знал про `node_modules`, а установка
  Playwright осталась в рабочей папке с другой ветки. Заметил, когда сборка PDF упала после
  смены веток. Исправлено обычным коммитом поверх (перезапись истории не разрешена), в диффе
  PR #3 и #5 файлов нет; вливать эти PR лучше через Squash. Вывод: перед `git add -A` смотреть
  `git status`.
