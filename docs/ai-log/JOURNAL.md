# Журнал работы с ИИ

Материал для разделов описания работы «время, расходы, ошибки и помощь человека» и «как шла
работа с нейросетями». Записи добавляются по ходу, а не задним числом.

Формат записи: дата · кто (человек / Claude Code / Codex) · задача → результат · ошибки ИИ и
как их нашли · что сделал человек. Расход — по `pf.py cost` или по счёту сервиса; если оценка,
так и пишем.

**2. Прогон без интерфейса.** Пять сценариев на вымышленных материалах (travel-eSIM, «Корзинка»,
фитнес-подписка) и тот же кейс в обычном чате для сравнения. Роль PM играл разработчик:
давал запросы, новые данные и отвечал на вопросы агента. Расход около 9,4 USD по тарифам API.
- Найдено и исправлено 7 проблем: от `impact`, не видевшего непроцитированное допущение,
  до субагентов, чьи составные команды запрещались и молча не попадали в реестр
  (таблица — в отчёте прогона).
- Помощь человека: ответы за PM, решение, что исправлять сразу, а что спрашивать у PM.

**3. Разбор репозитория и кейса.** Капитан → Claude Code (другая сессия): изучить кейс, затем
репозиторий команды. Claude прочитал кейс, весь код и инструкции и прогнал `pf.py` на
временной копии.
- Найдено: (а) 20 параллельных `claim add` сохраняли 16 записей без ошибки — реестр
  переписывается целиком, ID выдаются без блокировки, а skills советуют параллельных
  помощников; (б) Stop-хук печатал в stdout с кодом 0, который модель не видит, поэтому правило
  «исправь ошибки check» не работало; (в) в README была ссылка на отсутствующий документ
  об аудио и видео.
- Ошибка самого Claude: усомнился в цене Haiku 5.5 в `pricing.json` по памяти; сверка со
  справочником тарифов показала, что цена верная. Вывод: цены — только по справочнику.

**4. Исправления — PR #1** (https://github.com/NursuUwU/AI_agent_hack/pull/1). Claude Code:
