# Изображения, аудио и видео

Что агент делает сам и где граница. `pf.py` не вызывает моделей распознавания речи и не
ставит тяжёлых зависимостей: медиа превращается в текст и кадры, а дальше работает обычный
реестр источников.

| Материал | Как попадает в проект | Что из него можно утверждать |
|---|---|---|
| Скриншот, макет, фото | `pf.py ingest inbox/screen.png --kind image`, затем агент читает файл (Read) | Только видимое: элементы, тексты, порядок шагов. Догадки о поведении пользователей — `hypothesis` |
| Аудио интервью | расшифровка `.txt`/`.srt`/`.vtt` → `pf.py ingest ... --kind interview` | Факт о высказывании («Респондент 2 сообщил, что…»); обобщения — `hypothesis` |
| Видео (запись экрана, ролик конкурента) | расшифровка речи + кадры → `ingest` обоих | Видимое на кадре с таймкодом (`--loc "02:15"`) и сказанное |
| Сам файл `.mp3/.mp4/...` | `ingest` зарегистрирует его с хэшем, но текста не извлечёт | Ничего, пока нет расшифровки или кадров |

## Как получить расшифровку и кадры

Любым инструментом на стороне PM; инструмент и его стоимость записываются в журнал
(`pf.py log "... расшифровано через <инструмент>" --kind tool`, при платном сервисе —
`pf.py cost-add`). Варианты:

- субтитры площадки (YouTube, VK Видео, RuTube), если ролик открытый;
- локально и бесплатно: Whisper (`pip install openai-whisper`, нужен ffmpeg), например
  `whisper interview.mp3 --language ru --output_format srt --output_dir inbox/`;
- кадры видео — `ffmpeg -i demo.mp4 -vf fps=1/10 inbox/frames/f_%03d.png` (кадр раз в 10 с),
  затем `pf.py ingest inbox/frames --kind image`.

## Правила

- Расшифровка — производный источник: в `--note` укажите исходный файл и инструмент; при
  сомнительном месте сверяйтесь с записью, а не «додумывайте».
- Реальные интервью — только с согласия; имена и голосовые особенности, по которым можно
  узнать человека, в проект не попадают (см. `knowledge/methods/interviews.md`).
- Описание изображения моделью не доказывает поведение пользователей — это материал для
  UX-разбора по `knowledge/methods/ux-analysis.md`.
