# Анализ данных

## Паспорт данных — до любых выводов
Источник и дата выгрузки · строки/столбцы · единицы (₽ с НДС/без, тыс./млн, %) · период и
гранулярность · определения метрик (что такое «активный», «удержание») · пропуски · дубли ·
выбросы · смены методики в периоде.

## Методы по задаче
- Падение метрики → декомпозиция (сегмент × канал × платформа × когорта), сезонность (год к году),
  смена определения/трекинга.
- Удержание → когортные таблицы, кривые выживания, сравнение когорт до/после изменения.
- Экономика → юнит-экономика, чувствительность к допущениям (±20–50%).
- Сравнение групп → доверительные интервалы, а не только средние; малые n помечай.
- Качественные данные (отзывы, обращения) → кодирование по темам, частоты, цитаты.

## Воспроизводимость
Каждый расчёт — скрипт в `analysis/`, входные файлы по ID источника, результат — файл,
зарегистрированный как источник `analysis`. Ручные расчёты «в голове» модели запрещены.

## Типовые ловушки
Средняя по скошенному распределению · проценты от разной базы · сравнение неполного периода
с полным · ошибка выжившего · корреляция ≠ причина · парадокс Симпсона при смене состава сегментов.
