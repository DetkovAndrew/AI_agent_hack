# Анализ пользовательского опыта

Работаем по тому, что **видно** в материале (скриншот, запись экрана, открытая страница, стор).
Каждое наблюдение — с привязкой: «скриншот S012, экран оплаты: кнопка "Продолжить" ниже
первого экрана».

## Разбор экрана
Цель экрана → главное действие → иерархия (что видно первым) → текст (понятность, обещания) →
отвлекающие элементы → ошибки и пустые состояния → доступность (контраст, размер).

## Разбор пути
Шаги от входа до ценности · число действий и полей · точки, где требуется решение или данные ·
где пользователь узнаёт цену · где возможен отказ. Сравни с 1–2 конкурентами на тех же шагах.

## Ограничения
Скриншот не показывает поведение: «кнопка незаметна» — гипотеза, пока нет данных воронки.
Наблюдение интерфейса → `fact` (что изображено); вывод о поведении → `hypothesis`.
Отзывы в сторах — источник `opinion`, полезны для поиска тем, не для долей.
