# План проверки

Для каждой несущей гипотезы:
| Поле | Содержание |
|---|---|
| Гипотеза | [C…] |
| Ожидаемое изменение | метрика, направление, минимально значимый эффект |
| С чем сравниваем | контроль/A-B, до-после с учётом сезонности, когорта, бенчмарк |
| Срок наблюдения | с учётом цикла метрики (удержание M1 → не меньше 5–6 недель) |
| Объём выборки | оценка (для конверсии: n ≈ 16·p(1−p)/δ² на группу при α=5%, мощность 80%) |
| Нежелательные последствия | guardrail-метрики: отток, жалобы, каннибализация, нагрузка, маржа |
| Решение по итогу | порог «продолжать / доработать / остановить», кто решает |

Порядок: сначала самая рискованная и дешёвая для проверки гипотеза.
Синтетика и мнения экспертов — не способ проверки, только источник гипотез.
