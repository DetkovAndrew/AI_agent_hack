# Исправление контрольной когорты

Исходный ряд отзываем. Технические продления ошибочно считались оплаченными.
В той же когорте из 8000 после первого продления осталось 6720 оплаченных подписок,
после второго 5645, после третьего 4742. Представительный сценарий по обновлённой
выгрузке — 84% условного продления на каждом шаге. Горизонт, расходы, цены и правило
финансового допуска остаются прежними. Запуск согласовывается директором отдельно.

После отмены ответили на анкету 72 из 1280 участников первого периода, из них 18 отметили
цену. Это добровольная выборка, вопрос о причине отмены не проверялся экспериментом.
